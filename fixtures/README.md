# CPU regression fixtures v1

These small JSON files are generated by `fixture-tests --write <directory>` and
checked by `fixture-tests --check <directory>`. Do not regenerate them casually:
changes require contract/numerical review. They represent the present educational
model, not calibrated real sensor captures or a general scenario DSL.

The three observation fixtures contain 55 frames at 0.1 s, frozen default Config
values except scenario/objects, seed 42. Truth is in `evaluation_truth` only; the
tracker tests reconstruct solely the `observations` array. Intermittent visibility
includes the existing sequence 35–49 dropout. Observation identifiers are frame
scoped; they do not encode truth identity. These byte fixtures are produced on
Apple Clang 21 arm64; same-seed byte equality is checked within each platform. Persisted floating values
use absolute/relative tolerance 1e-12 to permit platform libm roundoff; integer
metadata and shapes remain exact. Linux execution is still required.

`analytic_tone.json` is a raw block matching frozen RawSampleBlock v1. Shape is
[channel=2][chirp=8][sample=32], I+jQ; phase is
`2*pi*(5*n/32 + 2*m/8) + channel*0.25`. Rectangular 32-point FFT has bin 5,
amplitude 32; slow-time 8-point FFT has bin 2, amplitude 8. Sample rate 1 MHz,
chirp period 1 ms, slope 1e12 Hz/s, wavelength 0.004 m. The educational FMCW range
is `5 * 299792458 * 1e6/(2*1e12*32)` m; Doppler velocity is
`2 * 0.004/(2*8*0.001)` m/s. A separate matched-filter test places the pulse
[1,j,-1] at delay 7, with convolution peak at index 9 and amplitude 3.

Raw parser bounds: input text 12 MiB, nesting depth 8, exactly 18 known fields,
131072 numerical pairs, supported two-channel dimensions; envelope clocks fit
internal signed 64-bit readings. Shape/timing/finite values are checked before
allocating the numerical I/Q buffer. JSON document parsing itself is covered by
the text byte/depth bounds. The engine has no hardware driver or path-based API.
