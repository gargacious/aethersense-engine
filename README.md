# aethersense-engine
Pure C++20 typed simulation, DSP and tracking library. Build through the parent
AetherSense workspace; no HTTP, device, GPU or frontend dependency. Public contract:
`include/aethersense/engine.hpp`. Tests: `engine-tests`, `engine-oracle-fixture`.
Vendored nlohmann/json 3.11.3 retains its MIT notice. See parent architecture and
verification documents for numerical conventions and current limitations.
